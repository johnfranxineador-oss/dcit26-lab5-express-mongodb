# Student Records REST API (DCIT 26 - Lab 5)

## Description
A backend RESTful API service built with Node.js, Express, and MongoDB using Mongoose to manage student records.

## Setup Instructions
1. Clone the repository: `git clone <YOUR_REPOSITORY_URL>`
2. Install dependencies: `npm install`
3. Create `.env` file based on `.env.example`:
   ```env
   PORT=5000
   MONGODB_URI=mongodb://127.0.0.1:27017/lab5_students
